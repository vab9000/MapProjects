## MapProjects

A place for me to keep all my projects related to Maps.

### MapSimulation

A historical simulation, inspired by the Paradox Map Game genre of games. Primarily a result of my frustrations trying to get Paradox games to simulate history in a semi-accurate way.

Currently under development, without much ability to actually run it.

### MapEditor

A custom image editor for me to make maps to run with MapSimulation. It has special features such as adding properties to apply to locations, and making sure all locations have different colors.

All features are working as intended currently.

### ProvinceGenerator

An algorithmic generator of a map for MapSimulation. Created as a temporary stopgap, while I create a custom map using the editor.

Currently finished, although it is not fully up to my satisfaction.

### PopCapEstimate2

A program to calculate the average poplation density of a specific geographic factor combination in the world.

Fully developed.
